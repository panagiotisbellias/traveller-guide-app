# traveller-guide-app
Service that produces city recommandations based on the preferences and criterias of a traveller and uses open data. Developed in the context of semester assignment for "Object-oriented Programming II' lesson and studies program of Department of Informatics and Telematics (DIT) at Harokopio University of Athens, Greece (HUA)

## Building and Running with NetBeans

1. Open the project in **NetBeans** (`File > Open Project`).
2. Right-click the project in the **Projects** view.
3. Select **Clean and Build** to generate the runnable JAR in `dist/Traveller_Guide_App_V2.5.jar`.
4. To run the application, right-click the project and choose **Run**  
   OR run the JAR directly:
    ```bash
    java -jar dist/Traveller_Guide_App_V2.5.jar
    ```
